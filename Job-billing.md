## Recurring Job
If we select recurring job then the billing section looks like this first of all `ref/billing/10.jpg`. Default is 'visit based' selected. We can see 'Invoice frequency' dropdown. This looks like `ref/billing/11.jpg`. Now if we select fixed price and save then the Billing section becomes this `ref/billing/12.jpg`.  Now at the top we see 'Edit invoice settings' and if we click to edit then a popup appear which is  this `ref/billing/13.jpg`. From here we can select Visit based and Fixed . On visit based mode if we click the repeat field we see these options `ref/billing/14.jpg`.  And on fixed mode we see these options on repeat field `ref/billing/15.jpg`. However we select any options and then all reminders get created auto. Reminders are bounded by schedule start and end date by default.  And reminders gets created by user, how frequently they wanna get reminded they can set in the  'Invoice frequency' repeat field. On reminder tab reminder items are loaded max 10, there is pagination so we can navigate and see other items on next page  `ref/billing/17.jpg`.  If we click on any reminder items we see a popup `ref/billing/18.jpg`  and on the popup we can see 2 button and if we click on 'Edit' button we can see this popup `ref/billing/19.jpg` where we can edit each item.

Now if we click on Invoice tab of Billing section `ref/billing/20.jpg` we can see status is upcoming and there is a create button since no invoices gets created and once we create an invoice and draft it we can see the status becomes 'Draft'. However when we click on the create button to create invoices for any due or completed visit then we see all completed, overdue, sometimes today and sometimes upcoming 1  visit list to create invoice `ref/billing/20, 21.jpg`.
